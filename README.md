# MineTogether Server List - discover multiplayer communities
 

MineTogether Server List brings safe multiplayer discovery to the MineTogether ecosystem.
It lets players browse and share servers directly from inside Minecraft, helping communities grow through visibility, not marketing.

Just drop this mod in both the client and server, and set "discoverability=public" in server.properties, then after a few minutes of connectivity validation, your server should appear in the built-in client discovery list.

Features

- In-game browser for servers

- Lightweight design with focus on discoverability, not ranking

- Optional listing for friends-only or private servers via invite

- Works seamlessly alongside MineTogether Community and MineTogether Partners

- No trackers, no pay-to-list, no external accounts required
